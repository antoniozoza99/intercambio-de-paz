# Intercambio Amazónico para la Paz

Landing page informativa del tour **Intercambio Amazónico para la Paz** (Sibundoy – Mocoa, Putumayo), organizado por **LAST Tourism Consulting**.

Incluye programa día a día, servicios incluidos, atractivos naturales, aliados, recomendaciones de viaje y lista de equipaje interactiva.

## Estructura
- `index.html`: página completa y autónoma (estilos, scripts, logo y fotos incrustados).
- `docs-fuente/`: imágenes originales (logo y fotos de los atractivos) por si se necesitan editar.
- `.nojekyll`: evita que GitHub Pages procese el sitio con Jekyll.

## Ver la página
Abre `index.html` en cualquier navegador. No requiere instalación.

## Publicar con GitHub Pages
1. En el repositorio: **Settings → Pages**.
2. En *Build and deployment*, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Guarda. En 1–2 minutos estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
